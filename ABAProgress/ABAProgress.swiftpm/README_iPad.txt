ABAProgress v0.12.0 — iPad Swift Playgrounds 실행용

[준비]
- iPadOS 17 이상과 최신 Swift Playgrounds가 필요합니다.
- GitHub Actions의 ABAProgress-Swift-Playgrounds 아티팩트를 내려받아 압축을 한 번 풉니다.
- 파일 앱에 나타난 ABAProgress.swiftpm 폴더를 탭합니다. 일반 폴더 안의 Package.swift를 따로 열지 않습니다.

[실행]
1. Swift Playgrounds가 ABAProgress.swiftpm을 연 뒤 패키지 준비가 끝날 때까지 기다립니다.
2. 상단 실행(▶︎) 버튼을 누릅니다.
3. 처음 실행하면 로컬 SwiftData 저장소가 생성됩니다.
4. 아동 → 프로그램 → 과제 순서로 생성한 뒤 Trial을 기록합니다.

[주요 입력]
- 탭: NA → + → - → NA
- 길게 누르기: NA 초기화
- 실행 취소: 현재 날짜와 세션 안의 직전 입력 복구
- 입력 즉시 자동 저장

[주의]
- 앱 삭제 또는 Playgrounds 프로젝트 삭제 전에 필요한 보고서를 내보내세요.
- 보고서 웹 편집과 AI 기능은 서버 주소 및 개인 접속 정보가 있어야 동작합니다. 기록·그래프·PDF는 해당 기능 없이 사용할 수 있습니다.
- 실제 아동 자료가 아닌 합성 자료로 먼저 실행 흐름을 확인하세요.
