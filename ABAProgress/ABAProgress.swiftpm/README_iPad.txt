ABAProgress v0.6 — iPad Swift Playgrounds 실행용

1. iPad에 Swift Playgrounds를 설치합니다.
2. ABAProgress.swiftpm 폴더를 Swift Playgrounds로 엽니다.
3. 상단 실행(▶︎) 버튼을 누릅니다.
4. 아동 → 프로그램 → 과제 순서로 생성한 뒤 Trial을 기록합니다.

주요 입력:
- 탭: NA → + → - → NA
- 길게 누르기: NA 초기화
- 실행 취소: 직전 Trial/전체 입력 복구
- 입력 즉시 자동 저장

QA 문서는 패키지 최상위 SCENARIO_VALIDATION.md를 참고하세요.
