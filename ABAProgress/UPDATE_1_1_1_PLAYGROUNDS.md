# 쉬운 ABA 1.1.1 · 빌드 20

ZIP을 압축 해제한 뒤 Easy_ABA.swiftpm을 Swift Playgrounds에서 여세요.
기존 프로젝트와 기록은 새 패키지 동작을 확인할 때까지 보관하세요.

## 화면 흐름

1. 아동 → 프로그램 박스: 프로그램명, 학습 영역, 실제 Trial을 입력한 최근 수업일.
2. 프로그램 → 과제 제목과 목표. 과제를 누르면 List 목록을 펼치거나 접습니다.
3. List 제목 옆 ‘진행중: List1’ 버튼 → 기록 날짜, 정반응 입력 화면.
4. 완료·중단 List 버튼 → 기존 기록이 있는 날짜만 확인·수정합니다.
5. List 완료 기준과 다음 List 생성 확인은 기록 화면에서 유지합니다.
6. 완료·중단 항목을 길게 누르면 현재 List에 다시 추가할 수 있습니다.

## 데이터와 검토 범위

- 기존 과제명과 목표가 같은 항목만 화면에서 묶습니다. 목표가 다르면 별도로 표시합니다.
- 저장된 과제·List 번호·Session·Trial을 이동하거나 복제하지 않습니다.
- ‘완료’는 List/과제의 종료 상태이며 하루 기록 완료와 구분됩니다.
- List 완료 기준은 기존처럼 프로그램 단위로 적용됩니다.
- 최근 수업일에는 메모만 있는 기록이나 미입력 Session을 포함하지 않습니다.
- 이미지·PDF·영상 렌더링과 기기 화면 검증은 실행하지 않습니다.
- Debug 빌드 및 규칙 검사 결과는 동봉 BUILD_INFO.json에서 확인하세요.
