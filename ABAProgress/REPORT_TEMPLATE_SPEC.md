# 기본 중간보고서 양식 — 구현 기준 및 확인 사항

## 원본 시각 점검
사용자 제공 A4 16페이지 PDF 전체를 이미지와 텍스트로 확인했다. 원본 PDF·아동/치료사의 신상·실제 임상 수치·사례 문장은 공개 저장소에 포함하지 않는다.

| 원본 페이지 | 구성 | 구현 |
|---|---|---|
| 1 | 보고유형/기간, 기관 로고·태그라인, 제목, 4행×4열 정보 표, SUMMARY | 동일 필드와 핑크 표/요약 구조. 기관 고유 로고는 미제공 리소스로 간주하여 ABA 문자 자리표시자 사용 |
| 2 | 영역별 최근 3회기 평균, STO 수, 색상 구간, 전체 성장 그래프 | 벡터 SVG 막대/선, 구간색·80% 선·최근값 유지·단계 시작 라벨 |
| 3–9 | 평가군 > 영역/목표 카드, L별 색상·분리선·숙달선, 학습 내용 | 목표별 SVG와 레벨별 학습 내용, 기본 2카드/섹션, 긴 내용은 자동 인쇄 흐름 |
| 10 | 도전적 행동 변화 | 직접 작성, 자동 생성 금지 |
| 11 | 종합 현황 | AI 초안/검토/직접 편집 |
| 12 | 이번 기간의 강점과 주요 변화 | AI 초안/검토/직접 편집 |
| 13 | 치료사 종합 소견 | 직접 작성 |
| 14 | 가정에서 함께 하기 | 직접 작성 |
| 15 | 다음 목표 | 직접 작성 |
| 16 | 확인 및 서명, 4열 표, 설명문과 핑크 테두리 마무리 | 이름·자격·날짜 수동 입력, 실제 서명은 빈 (인) 칸 |

모든 페이지: 기관명 머리말, 사용자가 설정한 저작권/출처, Page n / N 꼬리말.
원본 기관 로고, 특정 서체, 여백의 픽셀 단위 일치와 iOS 인쇄 엔진 최종 렌더링은 아직 검증되지 않았다. 원본과 완전히 동일하다고 표시하지 않는다.
기관의 원본 로고 파일이 제공되면 개인 데이터와 분리된 리소스로 추가해야 한다.

## 데이터 대응 (명시적 가정)
원본은 13개 프로그램 그래프에 총 22개 단계별 학습 내용이 있다.
따라서 현재 구현은 프로그램=그래프 카드, 프로그램의 기록된 레벨=STO, 레벨 안의 과제=학습 내용으로 대응한다.
이 대응은 PDF만으로 원 작성 프로그램의 내부 정의를 확인한 것은 아니다. 사용자 확인이 필요하다.
하루 레벨별 값은 해당 날짜에 유효하게 기록·완료된 개별 과제 정반응률의 산술평균이다.
레벨 준거 달성은 평균이 아니라 해당 일의 적용 대상 과제 모두가 기준을 연속 기록일 수만큼 충족했는지로 산정한다.
현재 자료만으로 알 수 없는 이전 목표 생애주기 이력, 삭제한 과제, 과거 목표 정의 변경은 재구성하지 않는다.

## 주의해야 하는 집계 차이
- 목표별 그래프: NA 제외, 미완료 제외, 실제 기록일만 등간격. 레벨 전환에서 선을 연결하지 않는다.
- 영역별 평균: 기록된 STO 각각의 최초/최근 3회기 평균을 구한 뒤 영역 내 동일 가중 평균. 3회기 미만이면 존재하는 회기만 사용.
- 표지 평균: 영역별 평균의 동일 가중 평균. 전체 성장 그래프의 첫/마지막 점과 다를 수 있다.
- 성장 추이: 첫 유효 관측 이후 각 프로그램의 마지막 관측값을 유지. 새 단계 첫 관측 시 새 값으로 교체. 목표 시작 전 0을 만들지 않는다.
- 원본의 ‘진행 중인 목표’가 완료 목표를 어느 날짜부터 제외하는지는 PDF로 확정할 수 없다. 현재 구현은 선택된 관측 목표를 유지한다. 이 차이를 확인해야 한다.
- 전체 성장 그래프의 80%는 원본의 공통 참고선이다. 실제 레벨별 기준이 다르면 목표 그래프에는 레벨별 기준을 별도로 표시한다.
- 1회 시도 단일 목표만 O/X로 표시한다. 혼합/평균 과제를 임의로 O/X로 바꾸지 않는다.
- 데이터 없음과 회색 비백분율 영역을 동일하게 취급하지 않는다. 현재 앱에는 비백분율 측정 타입이 없어 해당 영역을 임의로 생성하지 않는다.
- 완료 상태 배지는 현재 구현에서 관측된 모든 레벨의 기간 내 준거 충족 여부다. 원 작성 시스템의 종결 상태와 동일하다고 단정하지 않는다.

## AI 경계
원본 사례의 서술을 템플릿으로 복사하지 않는다. GUIDE_SCRIPT.md로 문체·구조·숫자 사용·금지 사항을 정의한다.
서버가 숫자 배열만 받고 집계한 통계를 Groq Chat Completions의 엄격한 JSON 스키마로 전달한다. 이름·생년월일·날짜·프로그램명·메모·서명은 전송하지 않는다.
매 요청마다 기본 미동의 화면에서 수신처·목적·전송 배열을 확인하고 승인한다. AI의 계열 번호는 응답 이후 기기에서만 프로그램명과 레벨로 치환한다.
이는 출력 구조 검증이며 임상 정확성을 보증하지 않는다. 사용자가 근거와 문구를 검토해야 한다.
치료사 소견 이후 필드는 AI 응답 스키마에 없으며 자동으로 작성되지 않는다.
