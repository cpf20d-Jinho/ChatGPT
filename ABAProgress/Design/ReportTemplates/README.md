# 쉬운 ABA 기본 수행 보고서 틀

2026-10-07 사용자가 제공하고 저장소 등록을 요청한 기본 보고서 양식입니다.

[원본 PDF](easy-aba-performance-report.pdf)

## 적용 상태

v0.13.0에서 이 PDF의 Contents를 앱 입력과 HTML/PDF 출력에 반영합니다. 기존 16페이지 중간보고서 명세보다 이 양식의 구성을 우선하며, 기존 집계·임상 규칙은 유지합니다. 페이지 수나 데이터 개수는 고정하지 않습니다. 여러 프로그램은 기록 묶음을 반복하고 긴 서술은 다음 페이지로 이어집니다. 구현 대응과 검증 범위는 [내용 점검](../../REPORT_CONTENT_AUDIT.md)을 참고하세요.

## 구성 및 입력 방식

| 구역 | 내용 | 입력 방식 |
|---|---|---|
| 머리말 | 로고, 쉬운 aba, 학생명, 생년월일, 생활연령 | 등록 정보 및 설정 |
| 보고서 정보 | 수행 보고서, 보고 기간, 주당 빈도, 세션 시간, 총 회기, 작성자 | 기록에서 산출 가능한 값과 직접 입력 구분 |
| 1. 개요 | 치료 목적, 사용 프로그램, 현재 수행, 중재·교수 전략, 도전적 행동, 장소·빈도·주요 영역·핵심 목표 | 직접 작성 |
| 2. 진행 과제 및 수행 기록 | 영역, 목표, 진행 과제(List), 수행 그래프 | 선택 기간의 프로그램·과제·기록에서 산출 |
| 세션 노트 및 가정 연계 사항 | 각 수행 기록 아래 서술란 | 직접 작성 |
| 3. 결과 해석 | 향상된 부분, 지원이 필요한 부분, 행동 변화, 전체적인 해석 | 직접 작성 |
| 4. 향후 목표 및 치료 계획 | 유지·일반화 목표, 신규 목표, 다음 중재 방향 | 직접 작성 |

## 구현 시 준수 사항

- 원본은 A4 세로 1페이지 예시이며, 과제 수와 서술량에 따라 페이지를 확장합니다.
- 제목과 1~4번 순서, 영역·목표·진행 과제 표, 그래프와 직접 작성란의 연결을 유지합니다.
- PDF의 이름·기간·회기 조건·과제 문구·그래프 수치는 예시입니다. 실제 보고서의 기본값이나 임상 데이터로 사용하지 않습니다.
- 그래프는 실제 기록일을 등간격으로 표시하고, NA와 미완료 기록을 기존 집계 규칙대로 제외합니다. 레벨 전환은 구분합니다.
- 주당 빈도·세션 시간 등 현재 데이터로 확인할 수 없는 값은 임의 생성하지 않습니다.
- 원본의 로고는 자리표시자이며 실제 기관 로고는 별도 설정합니다.
- 원본 PDF는 변경하지 않고 보관합니다. 이 등록만으로 앱 양식 변경이나 PDF 출력 검증이 완료된 것은 아닙니다.
