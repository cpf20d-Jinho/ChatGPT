# 쉬운 ABA 아이콘

`ProvidedIcon.png`는 사용자가 최종 제공한 `ABA의 사본 (1).png`의 픽셀을 그대로 사용한 1024 × 1024 RGB 아이콘입니다. 앱 아이콘과 시작 화면 로고에 동일한 이미지를 사용합니다. 제공 파일에 포함된 부가 메타데이터는 앱 자산에 복사하지 않았습니다.

배경은 아이보리이며 ABA 글자와 아래의 세 단계 데이터 표시는 리프 그린입니다. 글꼴의 원본 파일이나 사용 권한은 확인되지 않았으므로, 이 이미지를 FF Meta 글꼴로 다시 제작했다고 표기하지 않습니다. 이전 SVG 아이콘 시안은 제거했습니다.

현재 아이콘은 평면 PNG입니다. Icon Composer 문서나 Liquid Glass 아이콘은 아직 제작하지 않았습니다.
