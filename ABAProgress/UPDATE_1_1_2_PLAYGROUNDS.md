# 쉬운 ABA 1.1.2 · 빌드 21

ZIP을 압축 해제한 뒤 `Easy_ABA.swiftpm`을 Swift Playgrounds에서 여세요.

## 변경 사항

- 진행 중인 List에는 리프 그린 채움 버튼으로 `정반응률 체크`와 현재 List를 함께 표시합니다.
- 완료·중단 List는 윤곽선 버튼으로 기존 기록 확인 경로를 구분합니다.
- 과제 추가 화면에서 자동으로 결정되는 `귀속 List` 행을 제거했습니다.
- 도움말 물음표는 각 제목 바로 옆에 표시됩니다.

기존 과제·List·Session·Trial 데이터와 판정 기준은 변경하지 않았습니다.
Debug 빌드와 규칙 검사 결과는 동봉된 `BUILD_INFO.json`에서 확인할 수 있습니다.
