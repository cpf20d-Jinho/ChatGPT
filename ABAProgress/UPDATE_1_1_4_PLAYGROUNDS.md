# 쉬운 ABA 1.1.4 · 빌드 23

ZIP 압축 해제 후 `Easy_ABA.swiftpm`을 Swift Playgrounds에서 여세요.

- 프로그램별 경과를 학습 경과로 변경했습니다. 제목은 과제명이며, 각 List를 별도 그래프로 표시합니다.
- 예: 블럭 모방 → 그래프 → List1 자동차 모양. List2는 자신의 기록만 사용합니다.
- 다른 과제·List의 성적을 프로그램 평균으로 합치지 않습니다. 동일 이름이어도 실제 기록 ID로 구분합니다.
- PDF, 영역별 요약, AI 숫자 계열도 개별 학습 List 단위로 집계합니다. 영역·전체 요약은 요약 평균임을 유지하며 개별 학습 그래프와 구분합니다.
- AI에 이름·제목·날짜를 보내지 않습니다. 앱 안에서만 계열별 과제명과 List 제목을 확인합니다.
- 평가군은 학습 List별로 지정하며 기존 프로그램 분류는 초기값으로 유지합니다.
- 기간 내 준거 달성과 실제 List 완료를 구분합니다. 기존 완료 판정 규칙·저장 기록은 변경하지 않습니다.
- 집계 단위 변경으로 기존 보고서 검토 상태가 만료될 수 있습니다. 그래프와 서술을 다시 검토해 주세요.

Debug 빌드 및 데이터·개인정보 경계 검사를 수행합니다. 이미지 렌더링과 기기 실행은 수행하지 않습니다.
