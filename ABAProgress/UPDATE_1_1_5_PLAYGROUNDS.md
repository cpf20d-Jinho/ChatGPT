# 쉬운 ABA 1.1.5 · 빌드 24

압축 해제 후 Easy_ABA.swiftpm을 Swift Playgrounds에서 여세요.

- iPad 시간표는 실제 콘텐츠 폭을 7등분해 월~일을 가로 스크롤 없이 표시합니다. 큰 접근성 글자 크기에서는 목록으로 표시합니다.
- iPhone은 방향과 관계없이 목록만 표시합니다.
- 아동 상세에서 완료 프로그램 수·입력 평균을 제거하고 진행한 수업 시간을 표시합니다.
- 시간표 기준: 해당 날짜에 실제 시도 기록이 있는 프로그램 영역의 수업 시간을 합산합니다. 휴강 제외, 보강 포함, 겹치는 시간 중복 제외. 측정한 실제 수업 시간이 아닙니다.
- 같은 영역의 수업이 하루 여러 번 있으면 모두 합산합니다. 현재 기록은 수업별 시작 시각에 연결되어 있지 않습니다.
- 아동 상세·프로그램 화면의 이름을 큰 글씨로 콘텐츠 가운데에 배치합니다.
- 페이지·양식·탐색 막대의 배경을 아이보리로 맞췄습니다.

Debug 및 데이터 검사 결과는 BUILD_INFO.json에 포함됩니다. 기기 실행·이미지 렌더링은 수행하지 않습니다.
